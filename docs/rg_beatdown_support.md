# RG Beatdown Support

`configs/decks/rg_beatdown.json` に含まれるカードの、現在の対応状況です。

## 対応済み

- `1-0-002` ソードファイター
  アタック時、ターン終了時まで BP +2000
- `1-0-004` ランサー
  アタック時、相手ユニットへ 1000 ダメージ
- `1-0-007` ゴライアス
  オーバークロック時、相手ライフ -1
- `1-0-010` 不知火伍式
  アタック時、手札 1 枚を捨てたら BP +4000
  プレイヤーアタック成功時、相手 trigger zone を最大 2 枚ランダム破壊
- `1-0-012` 魔槍のリリム
  フィールドに出た時、相手ユニットへ 4000 ダメージ
  アタック時、相手 trigger zone を 1 枚ランダム破壊
- `1-0-040` ハッパロイド
  フィールドに出た時、1 ドロー
- `1-0-051` バルバトス
  フィールドに出た時、相手ユニットの基本 BP -4000
- `1-0-057` サプライズボックス
  自分ユニットが出た時、trigger カードを最大 2 枚引く
  効果解決後は trigger zone から捨札へ移る
- `1-0-061` 新品の鎧
  自分ユニットが出た時、intercept カードを 1 枚引く
  効果解決後は trigger zone から捨札へ移る
- `1-0-062` 何でも屋の陳列台
  自分ユニットが出た時、1 ドロー
  効果解決後は trigger zone から捨札へ移る
- `1-0-065` パワーショーテージ
  戦闘時、相手ユニット BP -2000
- `1-0-074` 英雄の剣
  戦闘時、自分ユニット BP +2000
- `1-0-081` 悪の覚醒
  戦闘時、アタック中の自分ユニット BP +3000
- `1-0-096` 不可侵防壁
  戦闘時、自分ユニット BP +3000

## 仕様上、いまは追加効果なし

- `1-0-044` キャットムル
  カードプールの abilities が空文字で、個別効果は未定義
- `1-0-048` ギガマムート
  カードプールの abilities が空文字で、個別効果は未定義

## 共通対応済みルール

- unit の `drive`
- evolution の `overdrive`
- 手札内 `override`
- 戦闘勝利時の clock up
- overclock 時の行動権回復とアタック制限解除
- trigger zone へのセット
- unit / evolution によるコスト軽減
- アタック時能力はブロック選択より先に解決
- intercept は攻撃側と防御側が交互に、多段で使用可能

## 今後の拡張候補

- 能力本文 JSON の汎用解釈
- 対象選択を伴う能力の選択肢提示
- trigger / intercept の「効果が及ばないため使用不可」判定の一般化
