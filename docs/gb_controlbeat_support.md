# GB Controlbeat Support

`configs/decks/gb_controlbeat.json` に入っているカードについて、現状実装でどこまで再現できているかを整理したメモです。

## Deck Summary

- 40枚
- 青 / 緑 / 無 のコントロール寄りデッキ
- 破壊時誘発、登場時誘発、反応型インターセプトを多く含む

## Supported in Practice

次のカードは、固有効果まで現在の実装で再現できます。

- `1-0-027`
  - `ロスト`
  - 破壊時、相手は手札をランダムに1枚捨てる
- `1-0-029`
  - `インターセプトドロー`
  - 破壊時、インターセプトを1枚引く
- `1-0-031`
  - `リバイブ`
  - OC時、自分の捨札から1枚選んで手札に戻す
- `1-0-033`
  - `リバイブ`
  - 登場時、自分の捨札のユニット1枚をランダムで手札に戻す
- `1-0-039`
  - `血塗られし報復`
  - 登場時、相手の Lv.2 以上ユニットをすべて破壊する
- `1-0-040`
  - 登場時1ドロー
- `1-0-043`
  - `チャージ`
  - 登場時 CP +2
  - `連撃・グラインドドロー`
  - このターンに別の緑 2CP 以上カードを使っていれば1ドロー
- `1-0-045`
  - `ブロッカー`
  - ブロック時 BP +2000
- `1-0-061`
  - trigger から intercept を1枚引く
- `1-0-062`
  - trigger から 1ドロー
- `1-0-069`
  - `絶妙な挑発`
  - 相手ユニット1体のレベルを3にする
  - この方法では OC による行動権回復 / アタック制限解除は起こさない
- `1-0-089`
  - `ムーンセイヴァー`
  - 自分のユニット攻撃時、相手の Lv.2 以上ユニット1体を破壊する
- `1-0-091`
  - `ダーク・アーマー`
  - 自分のユニットに BP +7000
  - 自分のライフ -1
- `1-0-092`
  - `エクトプラズム`
  - 自分のユニット破壊時、相手ユニット1体を破壊する

## Supported Core Rules Around This Deck

- `set_trigger`
- `drive`
- `overdrive`
- `override`
- `retreat`
- `attack`
- `block`
- 多段 intercept
- trigger 左から順解決
- unit / evolution によるコスト軽減
- クロックアップ
- overclock
- LIFE 0 決着
- ROUND 上限時の LIFE 比較決着
- 破壊時誘発
- 反応型 intercept

## Practical Note

`gb_controlbeat.json` は、現時点で「デッキ内カードの固有効果が未実装で動かない」という状態にはなっていません。

ただし、より広いカードプール全体では次のものはまだ未完成です。

- ability JSON の汎用 DSL 解釈
- 一部の上位ルール
- 未採用カードの固有能力
