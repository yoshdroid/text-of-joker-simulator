## Current Concerns

- `1-0-035`
  - `沈黙` の状態管理がまだ弱く、能力封止を盤面状態として持つ必要があります。
- `1-0-037`
  - 複合能力カードです。登場時強化、破壊時ロスト、成功時リバイブの3系統を個別に整理する必要があります。
- `1-0-041`
  - 「手札を2枚選んで捨てる。そうした場合、2枚引く」は複数選択コストの土台が必要です。
- `1-0-071`
  - 戦闘終了時までの全効果封印は、現在の event resolver 全体へ作用するため影響範囲が広いです。
- `1-0-088`
  - カードレベル参照と `【呪縛】` 付与の両方が必要で、状態異常の一般化が欲しいです。
- `1-0-095`
  - 戦闘中だけの `【貫通】` 付与は、一時キーワード付与の仕組みを追加したいです。

## Notes

- `full` は、現行のシミュレータ上でカード固有効果の主処理まで再現できていることを意味します。
- 今回は coverage を優先して、既存の resolver と choice 系に素直に乗るカードから実装を広げています。
- 次に手を入れるべき山は、状態異常管理、複数選択コスト、戦闘中だけの一時能力付与です。
